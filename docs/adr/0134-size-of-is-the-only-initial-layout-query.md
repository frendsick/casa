# `size_of[T]` is the only initial layout query

Casa initially exposes no `align_of[T]`, field-offset query, packed-layout control, or other layout intrinsic. `size_of[T]` is sufficient for the accepted generic contiguous-storage use:

- `alloc` returns storage aligned for every ordinary Casa type.
- `size_of[T]` includes the tail padding required for a valid element stride.
- Ordinary field access is generated by the compiler and needs no source-visible offset.
- Foreign aggregates and custom allocator or arena layouts are not part of the initial language surface.

## Consequences

- Generic collections allocate `count * size_of[T]` bytes and address elements with the same stride.
- Unsafe code obtains a field's actual address through typed field access followed by `ptr::from_ref`, rather than reconstructing its offset.
- Ordinary Casa layout remains opaque and non-ABI-stable under ADR-0127.
- A future `align_of`, `offset_of`, or explicit-layout feature requires a concrete FFI, arena, or hardware-layout need and its own stability contract.
