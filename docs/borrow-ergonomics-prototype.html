Borrowing without call-site noise

This throwaway prototype asks whether Casa's $T and mut$T types, automatic reborrowing, and diagnostics make borrowing clear in compiler, text, and collection code without another borrow expression.

Working recommendation: keep the two type sigils and automatic reborrowing. The source examples expose ownership at API boundaries and method names. Improve a small set of diagnostics instead of adding call-site syntax.
